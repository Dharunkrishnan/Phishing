# 🔐 Phishing URL Detection System

## 📌 Overview
This project is a Machine Learning-based web application that detects whether a given URL is safe or phishing. It uses feature extraction techniques and trained ML models to analyze URLs and provide predictions.

## 🚀 Features
- Detects phishing and legitimate URLs
- Extracts 30+ URL-based features
- Machine Learning model prediction
- User-friendly web interface (Flask)
- Real-time URL analysis

## 🛠️ Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas, NumPy
- BeautifulSoup
- Machine Learning Algorithms (KNN, SVM, Gradient Boosting)
